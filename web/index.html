Secure Authentication for IoT Devices

Run a local challenge-response demonstration. The device proves possession of a sample key without sending the key to the server.

Ready. Run authentication to see the exchange, or choose the walkthrough to attempt replay, tampering, and an unknown identity.
1 · ChallengeServer creates a fresh one-time value.
2 · ProofDevice signs it with HMAC-SHA-256.
3 · VerifyServer checks the proof and consumes the session.

Classroom demo only: the sample keys are public and embedded in this page. The walkthrough shows this server accepting and rejecting requests; it is not independent proof of production security. For a real deployment, use protected per-device keys, verified HTTPS, key lifecycle controls, and a security review.
